# Frontend Design Skill

**Name:** `frontend-design`  
**Description:** Create distinctive, production-grade frontend interfaces with high design quality. Use this skill when the user asks to build web components, pages, or applications. Generates creative, polished code that avoids generic AI aesthetics.

## Overview

This skill guides creation of **distinctive, production-grade frontend interfaces** that avoid generic "AI slop" aesthetics. The deliverable is real, working code with exceptional attention to aesthetic details and creative choices.

**Scope:** Apply when building components, pages, applications, or interfaces with visual requirements.

---

## Workflow: Design Thinking → Implementation

### Phase 1: Understand Context & Commit to Aesthetic Direction

Before writing any code, ask and analyze:

1. **Purpose & Audience**
   - What problem does this interface solve?
   - Who are the users?
   - What emotions should it evoke?

2. **Tone Selection** (Pick an extreme direction)
   - Brutally minimal / maximalist chaos
   - Retro-futuristic / organic & natural
   - Luxury & refined / playful & toy-like
   - Editorial & magazine / brutalist & raw
   - Art deco & geometric / soft & pastel
   - Industrial & utilitarian / [other distinctive flavor]
   
   **CRITICAL:** Choose ONE clear conceptual direction and execute it with precision. Bold maximalism and refined minimalism both work—**intentionality > intensity**.

3. **Technical Constraints**
   - Framework requirements (React, Vue, vanilla JS/HTML/CSS)
   - Performance needs
   - Accessibility requirements
   - Browser compatibility

4. **Differentiation**
   - What makes this UNFORGETTABLE?
   - What's the one thing someone will remember?

---

### Phase 2: Implement with Production-Grade Quality

Deliver code that is:
- ✅ **Functional & Production-Grade** — Works perfectly, handles edge cases
- ✅ **Visually Striking & Memorable** — Commits to aesthetic vision without compromise
- ✅ **Cohesive with Clear Point-of-View** — Every design choice reinforces the direction
- ✅ **Meticulously Refined** — Attention to every detail, from pixels to interactions

## Frontend Aesthetics Framework

### Typography
- **Reject generics:** Avoid Arial, Inter (unless intentional), Roboto, system fonts
- **Choose distinctive fonts:** Beautiful, unique, characterful choices that elevate the design
- **Pair strategically:** Distinctive display font + refined body font
- **Example pairings:** Playfair Display + DM Sans, IBM Plex Mono + Quicksand, Bodoni + Montserrat

### Color & Theme
- **Commit to cohesion:** Build around a single aesthetic, not scattered colors
- **Use CSS variables:** Maintain consistency across components
- **Dominant + Accent pattern:** 60-30-10 rule outperforms even distribution
- **Avoid:** Timid palettes, overused schemes (purple gradient on white), generic combinations

### Motion & Micro-Interactions
- **High-impact moments over scattered effects:** One well-orchestrated page load with staggered reveals beats random micro-interactions
- **CSS-first for HTML:** Leverage animation and transition properties
- **Motion library (React):** Use libraries like Framer Motion for React projects when animations require choreography
- **Scroll triggers & hover states:** Surprise with intentional, meaningful interactions
- **Performance:** Use `transform` and `opacity` for smooth, GPU-accelerated animations

### Spatial Composition
- **Break the grid:** Asymmetry, overlap, diagonal flow
- **Control density:** Either generous negative space OR carefully controlled density (avoid middle ground)
- **Unexpected layouts:** Hierarchy through position, not just size
- **Visual weight distribution:** Guide user through composition, not random placement

### Backgrounds & Visual Details
- **Create atmosphere & depth:** Don't settle for solid colors
- **Contextual effects:** Textures, patterns, grain overlays that match the aesthetic
- **Creative forms:**
  - Gradient meshes
  - Noise textures & grain
  - Geometric patterns
  - Layered transparencies
  - Dramatic shadows & depth
  - Decorative borders & elements
  - Custom cursors
- **Match implementation to vision:** Maximalist designs need elaborate code; minimalist designs need restraint and precision

## Anti-Patterns: What NOT to Do

❌ Generic AI-generated aesthetics:
- Overused font families (Inter, Roboto, Arial everywhere)
- Clichéd color schemes (purple gradients on white)
- Predictable layouts & cookie-cutter component patterns
- Design that lacks context-specific character

❌ Design without direction:
- No clear aesthetic point-of-view
- Safe, middle-ground choices
- Convergence on common solutions

❌ Mismatched complexity:
- Maximalist vision + minimal code = fails to deliver
- Minimalist vision + overengineered code = defeats the purpose

❌ Bland defaults:
- Generic spacing
- Timid color choices
- No distinctive voice in typography or interaction

## Implementation Checklist

- [ ] **Aesthetic Direction:** Clear, articulated, extreme enough to be memorable
- [ ] **Typography:** Distinctive font choices, strategic pairing
- [ ] **Color System:** CSS variables, dominant + accent palette, cohesive theme
- [ ] **Motion:** High-impact choreography or refined restraint (never mid-ground)
- [ ] **Spatial Composition:** Intentional, not default layouts
- [ ] **Details:** Every pixel, shadow, border, cursor reflects the vision
- [ ] **Functionality:** Code is production-grade, handles edge cases
- [ ] **Performance:** Animations smooth, images optimized, bundle reasonable
- [ ] **Accessibility:** Semantic HTML, ARIA labels, keyboard navigation, contrast ratios
- [ ] **Browser Compatibility:** Tested across target browsers
